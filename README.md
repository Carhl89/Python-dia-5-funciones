# App de Asistencia - Python

Aplicacion de consola desarrollada en Python para gestinar alumnos.
Proyecto creado como practica para aprender programacion, Git y desarrollo profecional.

---
## Funciones actuales

* Agregar alumnos
* Eliminar alumnos
* Listar alumnos
* Guardado automatico en csv
* Carga automatica al iniciar
* Codigo modularizado (modelo / main)

---

## Tegnologias usadas

* Python 3
* Git
* Github
* CSV
